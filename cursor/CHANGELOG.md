# Changelog

All notable changes to this plugin will be documented here.

## 1.0.0 — initial release

- Added the `datagate` MCP server pointing at `https://mcp.dgportal.net/mcp`, authenticated with a Datagate public API key declared as the `DATAGATE_API_KEY` plugin variable.
- Added the `working-with-datagate` and `mcp-auth` skills.
